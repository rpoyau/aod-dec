# Particle example evidence

[The application guide](../../docs/PARTICLE_EXAMPLES.md) gives portable commands,
preparations and exact outputs. The `outputs/` and `review/` records here preserve
the original source-bound calculation and its independent saved-witness checks.

The published runners use repository-local executable dependencies. Their
manuscript hashes are explicitly recorded historical bindings, not assertions
that absent manuscript files were reopened. The publication port preserves every
non-provenance result exactly and retains a byte-identical proton witness archive.

[Publication comparison](publication/execution.json) records both Python modes
and the explicitly permitted metadata differences. Original source bindings and
execution records remain unchanged; [IMPORT.json](../scoped-current/IMPORT.json)
maps their bytes into this repository.

The proton rows are non-additive alternative windows; the burden-to-signed-current
projection remains unresolved. Electron rows are successive native responses.
Neither output claims an uncomputed scattering or force measurement.
