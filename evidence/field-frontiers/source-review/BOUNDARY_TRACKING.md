## Object tracking is a dependency graph

- **Monon:** a certified retained-start branch/hinge/counterbranch closure. Track pending path separately from admission, then immutable return and certificate. Endpoint equality alone is insufficient (`Main04:6–43`).
- **Dion:** oriented two-position pattern around a retained Monon hinge; it is not a two-Monon closure and not a wave (`Main05:25–31,110–119`).
- **Duon:** two Dion patterns plus a bound carried Monon pivot and returned-current witness. Its Duad seating is mutable state of the same identity (`Main05:33–56,89–119`).
- **Trion/Trio:** threefold core, `3:1`; `3:j` composes j such units. Track the admitted construction and actual survival/retention/route status. The owner's instability clarification is a reason to retain short-lived/pending/routed states, not to inject a universal decay probability (`Main05:120–121`; `Appendix B:46–78`).
- **Tetron:** E4 four-seat inner enclosure. Tetrion is a bare four-cycle/four-pivot return, tetratrion is `3:4`, tetrad is seated Tetron. A partial boundary cut does not change complete enclosure identity (`Main05:224–225`; `Main06:709–746`; `Appendix B:46–57`).
- **Recurring wave / field:** at least two compatible distinct completions admit a wave. A field resolves unique wave identities; labels and boundary moves add no closure. Its membership/state and archives can change without replacing its identity (`Main04:116–150`; `Main05:164–188`).

Trion, Tetron and a four-edge path are therefore not consecutive stages of one unconditional ladder. Named support, enclosure, completed return, recurrence, seating, current and route status should be independent fields with source-bound dependencies. This permits transient curls to be tracked without prematurely classifying them as stable fields.

Main `sections/06_field.tex:610–674,782–790` provides concrete mutable route predicates: exact closure residual; positive surplus versus deficit; declared sheddic route partition; seat-compatible TTL versus the window; and optional odd-window Yro status. A Trion label alone establishes none of these. Yro is a route-status suffix, not an odd enclosure or a synonym for every Trion. No quantitative universal Trion lifetime was found in the inspected named definitions; this review introduces none.

Check each new event's identity/context binding against the persistent union, validate the new closure/motif dependencies and append invariants, and update only affected wave/field indices. Caching a successful object never discharges cross-object contradictions. Do not key by display label, scalar RD, claimed digest alone, Python equality that merges booleans and integers, or a current aggregate. Reopened external bytes require integrity and canonical validation before reuse. Cache eviction affects cost; lost archive coverage affects claims.
