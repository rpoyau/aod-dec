# Boundary-frontier implementation review

The new compact frontier admits each complete recurring native Wave cold and retains its canonical formation evidence in a content-addressed disk archive. Active state keeps identity, motif, scope, scale, half-open response window, coupling binding, committed cut, exact pressure/current, historical closure count and cadence, witness reference, field-weight metadata and unresolved obligations. It contains no complete returns, certificates or nested inner Waves. Supplied-attention response uses the unchanged native inverse-pressure update directly on that compact state.

The SQLite retained-history index checks the union of terminal identities, event coordinates, wave identities and immutable recurrence prefixes, including nested motifs and folded ancestors. Removing an active field does not erase retained bindings. Reopening reconstructs the derived index from hash-checked, strictly typed, canonically validated witness files. An error after witness writing starts prevents further admission until reopen, because a durable file can outlive an index rollback. Hot updates neither read this index nor reopen the witness archive.

Registration snapshots copy exact rational numerator/denominator pairs and reference strings. Altered/stale summary or attention values cannot acquire admission through object identity or Python Boolean/integer equality. Exact native schemas permit Boolean values only for the reflected-comparison flag. Changed window, scale or coupling, unresolved routing obligations, and window expiry require explicit exposure/model rebinding. Response steps do not create new closure witnesses, recurrences or shedding evidence. The archive preserves historical formation; callers must separately journal response histories if those are needed.

The indexed queue keeps one pending entry per registered field, replacing it in place, with O(log n) heap work for schedule/pop/cancel. This bounds queue entries by active fields. It does not bound arbitrary interaction-edge work, total historical disk storage, rational operand bit complexity, or whole-engine execution by the same asymptotic expression. Explicit count and scalar budgets bound each live entry. Field weight is positive exact mapping metadata (default one), not a power-of-two octave scale and not a pressure-response multiplier.

Existing reusable abstractions have narrower proof domains. `scoped_reduction.py` establishes exact finite-kernel quotient behavior, while `recurrence_cache.py` checks complete quotient-state recurrence under its bound update domain. They do not by themselves prove that a boundary scalar is sufficient for an arbitrary native formation law. The new frontier proves only the existing response-law sufficient operands. `RetainedHistoryUnion` supplies the joint-history checks; the strict native decoder and producer validators supply formation admission; recoverable archival evidence supplies explicit exposure. Full-value digest caching alone would still walk interior history and is therefore not the hot-path strategy used here.

Seventeen focused tests pass normally and with Python -O. They compare exact compact response trajectories against expanded native states and an independent rational sum; prohibit hot wave validation/archive/index access; recover Monon, Duon, generic 3:1 support and folded inner histories after reopen; reject combined-history conflicts before and after removal/reopen; reject Boolean certificate scales and integer reflection flags; reject altered/stale/aliased values and failed or single closures; verify archive hashing and canonical validation; model failure after durable rename; and check randomized scheduler operations against an independent dictionary oracle. The generic 3:1 construction is not promoted to an unsupported stable Trion or Tetron species claim.

Files and versions are bound in SOURCE_BINDING.json. No Main/Manual manuscripts or vendor semantics were changed by this implementation. Root owns integration benchmarks, documentation, scientific lint and delivery.

Explicit `rebind(summary, window=..., coupling_id=...)` cold-exposes the same historical witness and preserves the advanced committed cut, current, pressure, field-weight metadata, scale, pending obligations and closure evidence. It requires the new window to contain the current cut, increments generation and invalidates previous attention. It cannot resolve pending obligations or migrate a native scale. Tests cover recoupling after exact response steps, failure atomicity, excluded-cut rejection and unresolved-route preservation.
