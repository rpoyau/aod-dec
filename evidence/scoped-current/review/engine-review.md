# Independent regional adapter review

The repaired regional adapter passes the independent finite checks within its declared accounting scope. Two material defects were reproduced during active implementation and corrected by the implementation agent: a pending burden could disappear from later boundary views, and ordinary Python numeric equality could admit float or Boolean replacements for exact cached quantities. Both falsifiers now reject or preserve the required record as appropriate. The exact counterexample preparations and observed pre-fix results are retained in `engine-counterexamples.json`; a full copy of each superseded intermediate source was not retained.

This review did not edit production code. It inspected the source and executed a separate 41-check adversarial script, `check_region_engine.py`, normally and with `-O`. Both passes produced identical saved evidence. It did not rerun the maser/Earth examples, compiler suite or physical simulations. The selected final implementation, examples, tests, scalar compiler checks and evidence are bound in `engine-review-hashes.json`.

## Findings and repairs

**R1 — pending projection persistence, fixed.** An obligation from cell `a` to `b` was committed while both cells lay inside the boundary. The next cut had no new obligations, and the boundary shrank to include only `a`, with an explicit zero-valued sweep for `b`. The old implementation examined only obligations newly introduced at each cut. It therefore admitted `scope="full"` and reported no unresolved projection at the second cut. The repair accumulates the outstanding obligation prefix before evaluating each later boundary membership. The later row now retains the obligation, and a full-current request rejects. This directly checks the user's concern that a changed boundary cannot erase previously pending content.

**R2 — exact cached quantities, fixed.** For a channel with `Fraction(1)`, replacing cached row and total values with `1.0` or `True` passed the old equality-only validator, because those Python values compare equal. The repair requires both reconstructed equality and exact canonical fingerprint equality. Independent float and Boolean mutations now reject. The implementation tests additionally exercise nested projected values.

**C1 — completeness scope, clarified.** A locally computed snapshot proves consistency with the supplied committed family. It does not prove that a native producer or external acquisition supplied every physical event. The final audit carries this limitation in `coverage_claim`; `scope="full"` additionally rejects known unresolved crossing projections. An explicitly empty supplied family may have exact zero current, but the result does not certify an empty physical system. Rehashing a different source family produces a different preparation, not a successor to the old committed prefix; that successor claim is rejected.

**C2 — compiled sweep domain, aligned.** The initially inspected scalar `swept_current` helper accepted a negative measure, while host `SweepSample` requires a nonnegative measure and uses membership change to supply orientation. Root added the matching nonnegative assertion and a sixth hostile compiler case. The final compiler evidence binds that corrected source. This was a domain-consistency correction, not a change to the signed moving-boundary equation.

## Substantive checks

The independent script constructs one forward occurrence of value 4 and a different reverse occurrence of value 2. Region `a` correctly gives 2, region `b` gives −2, and their union gives 0; both histories survive. An inactive channel and a self-channel remain in the retained source but do not create an outward transfer. Empty and whole regions return zero. A core/shell disjoint partition agrees with the parent; an overlapping partition rejects.

Unknown region cells, unknown channel endpoints, repeated cells, duplicate physical occurrences, float/Boolean currents, noninteger cut/window inputs and non-Boolean availability reject. Deleting a channel without updating its source snapshot rejects; rebuilding a truncated history and presenting it as a successor of the original also rejects. Partition comparisons with changed domain, quantity unit, scope, participation window or representation map reject.

For moving regions, one same-cut sample assigns swept measure 3 to cell `b`. A child that gains `b` has sweep +3, a complementary child that loses it has sweep −3, and their unchanged parent has sweep 0. The moving partition identity passes using that one shared sample. Missing sweep coverage and a forged sample reject. The source explicitly chooses AFTER membership for crossing selection, and successive frames must connect without a gap.

The `RepresentationMap` check converts a current by factor 1/2 from source scale 0 to declared representation scale 2 while retaining the original source history. The same factor applies to crossing, sweep and signed shedding quantities. An incompatible unit rejects. This is an explicit representation conversion; it does not admit a new higher-scale native closure. Constructing a source ledger at higher native scale still rejects because the ancestral-support bridge is outside this adapter.

Pending obligations remain outstanding in this adapter; there is no new receipt/resolution API here. Existing route receipts and native support admission remain in their owning lower-layer interfaces. Supplying or certifying a resolved signed-current projection is a separate producer responsibility. The adapter makes no stock-balance claim.

## Example and compiled-surface interpretation

Read-only inspection of `examples/run_regions.py` confirms a declared D0 source inventory and explicit native-helper operands, rather than a claimed generated maser or gravitational law. Its immutable preparation list is checked against the committed channel list before boundary selection. The native `RCD`, participation, `aod_flux` and `stokes` helpers calculate the declared values; these scalar inputs do not constitute formation certificates for a physical apparatus or planet.

The maser preparation deliberately balances pump magnitude `2u` against two outward branches `u+u`, with effective `u=(4,0,4,5)` under the supplied windows and gates. Thus output transfer is nonzero while the apparatus's net boundary current is zero. This is a declared balance, not an inferred stationary oscillation.

For the Earth/water-shell/Moon preparation, let the Moon gate be `g=(1,1,0,1)` and sweep be `(0,3,0,−3)`. Water-shell crossing is `−4+12g`, signed shedding input is 2, so the exact moving totals are `(10,7,−2,13)`. Core and Moon contributions cancel their internal transfers in the combined boundary, leaving `(2,−1,2,5)`; the complementary region has opposite totals and the universe cancels. The surface movement and signed shedding are declared inputs. The script does not claim that gravity, a constitutive law or a burden-to-current conversion produced them.

The separate packet script consumes the Manual metrology ancestry validator. The declared window has three emissions, two arrivals, one initially pending packet and two finally pending packets: `3−2=2−1`. That count domain remains separate from pressure-current and oscillator phase.

`examples/region_current.dec` implements scalar clipping, orientation, sweep and moving-current expressions. `checks/verify_region_dec.py` compares independent expected rational values with reference execution, generated ORC specialized/fallback execution and an AOT executable. Its saved evidence checks nonzero machine-code addresses and the expected emitted sequence. Collection coverage, cell-set construction, history retention and source admission remain host responsibilities; the compiled expressions are not a compiled replacement for this entire regional adapter. The compiler checks were inspected as saved execution evidence, not rerun by this reviewer.

Coverage is this regional adapter, its relevant bound lower-layer interface, the source/data flow of the two examples and the scalar compiler surface. The source review in `sources.md` supplies the Main/Manual contracts. No universal all-scale dynamics, empirical tide/force/maser prediction or cost-inclusive performance result is inferred from these finite passes.
