# Semantic IR v1 and source bindings

The authoritative closed schema is the canonical output of
`runtime.dec_language.compile_source`; `loads_ir` regenerates that schema from
embedded source and requires byte-equivalent canonical JSON. Both public native
lowering and JIT/AOT entry points call that verifier. A permissive JSON Schema
alone would not validate types, definite assignment or dispatch.

Top-level fields are `format="aod.dec.ir"`, integer `version=1`, UTF-8 `source`,
hex `source_sha256`, and ordered `functions`. A function contains `name`, ordered
`params`, `output`, declaration `line`, and overload `branches`. Each branch
contains typed ordered parameter records, `return_type`, `output`, signature
`line`, and ordered `body`. Body kinds are `assign`, `assert`, `emit`, `return`;
each has its source `line` and typed expression `value`. Assignments additionally
contain `name` and `type`. Expression kinds are `literal`, `name`, `call`,
`binary`, `unary`, `compare`, `boolean`, `conditional`, with exactly the child
fields generated by the parser. Unknown keys, duplicate keys, modified typed
values, source mismatches and wrong hashes are rejected. Serialization is
deterministic sorted-key JSON with explicit type tags and exact integer literals.

The lowered LLVM control-flow representation preserves one function per exact
overload, ordered runtime calls for checked arithmetic and effects, explicit
branches/phi values, direct recursive calls and common failure exits. The LLVM
verifier runs before object emission. Source line numbers are operands to the
native helpers; logical fuel counts reference expressions/statements/calls.
The C ABI defines opaque immutable values and context ownership separately.

The compiler's finite trace specialization is not the full folded-cell-complex
ontology. Existing general finite AFC helpers remain Python reference fixtures;
no new native collection-based AFC surface is claimed. Current owner amendments
take precedence over older field-first source wording within their declared
scope. No Main or Manual source was changed. Timing and policy selections are
compiler implementation choices and supply no SI anchor or physical transition law.
