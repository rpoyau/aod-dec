# Dec compiler instructions

Use the AOD and AF guidance from `rpoyau/aod-skills`, with the exact revision and
authority reconciliation in [docs/SKILLS.md](docs/SKILLS.md). Bind the target
source and current owner instructions before making a semantic claim. The
repaired Dec core is a declared finite implementation, not a replacement for AOD
ontology. Use AFC only for an applicable declared finite-memory/kernel fixture;
General Mechanics supplies compatible scientific presentation.

Preserve exact integers/ratios, checked ternary intermediates, explicit dispatch,
source-located failures, ordered effects, logical fuel, immutable event identities,
scope/lineage and retained parent/witness records. Keep the reference VM and use
independent expected values and hostile witness tests alongside differential
tests. A matching pair of implementations is not an independent proof.

Keep native compilation, JIT execution, persistent policy influence, measured
performance and self-hosting claims separate. A native executable must execute
lowered source behavior; JIT evidence must invoke generated machine code. Hardware
timing and implementation selection add no AOD clock or physical dynamics. Preserve
zero/negative benchmark results and failed/censored observations.

Use the pinned `rpoyau/aod-lint` integration described in
[docs/LINT.md](docs/LINT.md). Report its actual inspected scope and unsupported
checks. Static scans do not establish compiler semantics, scientific validity or
publication-build success. Do not manufacture manuscript inputs for this compiler
repository.

Run checks relevant to changed behavior, including normal and optimized Python
tests and native conformance/runtime tests for backend changes. Retain source and
toolchain identities with evidence. Keep generated build caches and credentials
out of source commits; record environment-specific paths in toolchain/evidence
records. Explicitly inventory unsupported grammar and targets.

Current owner instructions govern remote actions. Historical manuscript locks,
milestone gates and PR requirements in dated skill/project records do not create
new permissions or block unrelated compiler engineering. This repository does not
authorize edits to AOD Main/Manual or other upstream repositories.
